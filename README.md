# AI Resume Screening with DistilBERT

An AI-powered resume screening application using DistilBERT and Streamlit.

## Features

- Resume text classification
- AI-based job role prediction
- Model confidence score
- Job match score
- DistilBERT transformer model
- Streamlit web interface
- Resume dataset
- Trained model included

## Job Categories

- Backend Development
- Cloud DevOps
- Cyber Security
- Data Science
- Deep Learning
- Web Development

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- DistilBERT
- Scikit-learn
- Pandas
- Streamlit

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app/app.py
